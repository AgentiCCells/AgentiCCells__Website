# Part of a stack

AgentiCCells is one of several separate ventures that use each other. Dinis Cruz maps them in [The intersection](https://newsroom.sgit.ai/articles/the-intersection.html) (newsroom.sgit.ai, 2026-11-16). This page says where we sit and links up and down the stack. No money changes hands between the ventures; the uses are real, the transactions are not (the same article says so).

## Under us

- **[SGit](https://sgit.ai/):** git for encrypted vaults. Our cells keep their work in vaults and message each other on lanes.
- **[SHarness](https://sharness.ai/):** a behaviour policy for every process an agent starts, enforced by the kernel.
- **Keys:** a key for every person and every agent. [A key for every person](https://newsroom.sgit.ai/articles/a-key-for-every-person.html).
- **[Agent Behaviour Policies](https://abp.sgit.ai/):** the standard under all of it, housed at RiskMandate for now.

## Beside us

**[RiskMandate](https://riskmandate.ai)** writes the behaviour policy. Already running agents and need to control them? RiskMandate writes the behaviour policy, from one agent to hundreds. We sell the team; they sell the control. A team is usually set up with its policies, so a dual sale is possible. Both sites sell on [one ladder](/cells/); every price on this site is a first proposal.

## Worked examples to read

Three newsroom articles of 17 November show pieces a cell could be made from. None is sold as a cell yet; each says what it does not claim.

- [Deploy sgit from CI](https://newsroom.sgit.ai/articles/deploy-sgit-from-ci.html): a team runs its own sgit server in its own cloud account, using the pipeline pattern of our site factory.
- [Shipping an iOS app with agents](https://newsroom.sgit.ai/articles/shipping-an-ios-app-with-agents.html): agents without a Mac build, test and send a native app to testers.
- [Build on VoiceDebrief](https://newsroom.sgit.ai/articles/build-on-voicedebrief.html): the techniques of an open-source voice app, with the code to read.

## How the work is handed out

One person sets the work and owns the outcome. One conductor agent hands it out and collects the reports. Specialists, each with a role and a behaviour policy, do it. A reviewer checks every claim. A person decides what goes out; agents never send or post. Dinis Cruz sets this out, with one addition (a file every agent reads first, so the door can close), in [Who hands out the work](https://newsroom.sgit.ai/articles/who-hands-out-the-work.html).
