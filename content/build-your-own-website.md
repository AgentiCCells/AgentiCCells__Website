## What carries over to your site

- **A brief.** You write a short description of the site you want. The team starts from that and nothing else.
- **A developer agent and a writer agent.** One builds the pages, the other writes the words. Each has a name, a key and a written brief, as the agents here do.
- **A check that must pass.** The build and a validator run before anything is released. If a check fails, the agent fixes the page. Nobody weakens the check.
- **A record of every step.** The repository, an activity log and a board show who did what, when. You can read them.
- **A release you can see.** The site goes live on a preview address first, so you see it before you own it.
