# Open source

The software in a cell is free and open. What we sell is the setup, the guidance and the trust. Anyone can rebuild what we deliver, and we think that is right.

Each licence below was checked on 15 November 2026 against the project's own licence file or package registry entry. The list, the sources and the dates are kept as data in [data/stack.json](https://github.com/AgentiCCells/AgentiCCells__Website/blob/dev/data/stack.json). The list of components comes from [Selling mini agentic teams](https://newsroom.sgit.ai/articles/selling-mini-agentic-teams.html).

## The open components

- **The workflow.** Briefs, a board made of files, conductors, hand-overs and releases. A method written up in articles, not a package. Licence: text CC BY 4.0, code Apache-2.0. [Link](https://newsroom.sgit.ai/articles/selling-mini-agentic-teams.html).
- **Ruflo.** rUv's open-source agent orchestration. Licence: MIT. [Link](https://github.com/ruvnet/ruflo).
- **sgit.** Git for encrypted vaults: the server stores your files only as ciphertext. In beta, by its own account. Licence: Apache-2.0. [Link](https://sgit.ai/), [code](https://github.com/SGit-AI/SGit-AI__CLI).
- **Files in git instead of databases.** The team's state lives as markdown and JSON in git and in sgit vaults. A practice, not a package. Licence: CC BY 4.0 (the article). [Link](https://newsroom.sgit.ai/articles/the-new-data-lake.html).
- **Our console.** The team's read-only console, built from this repository's files. Licence: code Apache-2.0, text CC BY 4.0. [See it](/console/).
- **The simulated console.** A made-up control room in a public vault, linked from its article. Licence: not stated on the vault. [Link](https://newsroom.sgit.ai/articles/an-agentic-console.html).
- **This website.** Markdown and JSON, built by Node, gated by a validator. Licence: code Apache-2.0, text and images CC BY 4.0. [Repository](https://github.com/AgentiCCells/AgentiCCells__Website).

## The runtimes you choose

Agents need a runtime. You choose it, and the models it calls are a paid service from their maker. These are not components we release.

- **Claude Code.** Anthropic's command-line agent. Not open source: use is under Anthropic's commercial terms. [Link](https://github.com/anthropics/claude-code).
- **Codex CLI.** OpenAI's command-line coding agent. Licence: Apache-2.0. [Link](https://github.com/openai/codex).
- **Cloudflare Workers.** The workerd runtime is open source under Apache-2.0. Running it on Cloudflare's network is a hosted service with its own terms. [Link](https://github.com/cloudflare/workerd).

Code we write is under Apache-2.0, or MIT where a dependency needs it. Text, guidance and images are under CC BY 4.0.
