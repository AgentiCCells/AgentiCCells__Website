# ACC-011 · sgit in the sessions, and where private keys live
Owner: conductor@AgentiCCells.dinis · Status: Done (2026-11-15)
2026-11-15: `sgit` was missing. The updated pack (READING.md) gives the install: `pip install sgit-ai`. Installed in the conductor's session: sgit-ai v0.27.0.
`sgit pki keygen` asks for a passphrase to protect the private keys and stores them in the session. Sessions here are ephemeral containers, so a key made now is lost when the container is reclaimed, and the passphrase is itself a secret with nowhere safe to go yet.
Ask Dinis: which sgit vault holds each agent's private key and passphrase (the "session's vault" in ACC-002), and how a new session gets it back. Until then no keys are generated, and team/keys.json stays empty.

Answer, 2026-11-15, Dinis: private keys live in each agent's session and are ephemeral; public halves go in the repository; write access to the repository is the authorisation. See team/keygen.sh.
