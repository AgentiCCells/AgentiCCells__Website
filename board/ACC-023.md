# ACC-023 · Count what the team costs, per role and per run
Owner: conductor@agenticcells.dinis, console@, reporter@ · Status: In progress
Source: Dinis, newsroom, 2026-11-15, "Spend fewer tokens" (https://newsroom.sgit.ai/articles/spend-fewer-tokens.html), read in full at 18:3x. "What is not measured grows." "An agentic team's token bill is mostly a design choice." The levers: files as memory, caching what repeats, code instead of models where you can, the right model for each step, no copy and paste, static outputs, and an accountant agent that makes the cost visible.
Already true here: files as memory (board, briefs, REALITY.md), static site, scripts for repeated steps (build, gates, keygen, release), Sonnet for every agent run (Dinis, 2026-11-15).
Work: at each wake the conductor reads each finished run's result (cost in API-equivalent dollars, turns, duration) and appends it to team/costs.jsonl; console@ shows cost per role and per day (C5); reporter@ adds it to the case-study numbers (R6). Mark every figure "API-equivalent", as the article does.
