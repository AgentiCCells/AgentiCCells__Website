# ACC-002 · Keys for the first agents
Owner: conductor@agenticcells.dinis · Status: Idea
Each agent makes its own key pair in its own session (sgit pki keygen) and publishes only the public half in team/keys.json (id, label, fingerprint, public key, created). Private halves stay in each session's vault. The gate rejects any private key in the repository.
Done when: conductor and dev keys are in team/keys.json and the validator checks the file.
