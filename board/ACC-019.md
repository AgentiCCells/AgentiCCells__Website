# ACC-019 · How an agent signs its commits with its own key
Owner: conductor@agenticcells.dinis · Status: Waits on Dinis
Raised by dev@, writer@, researcher@, console@ and abp@ on 2026-11-15. CLAUDE.md says "sign your work with your own key", but no route exists for signing git commits with an sgit key, and every commit is signed with the same SSH key from the container's git config. In a shared container a per-agent key would prove little anyway (security@, abp@). Dinis's rule (2026-11-15): authorisation is write access to the repository; keys identify. Options: (a) leave commits as they are and sign only lane messages and debriefs with `sgit pki sign`; (b) per-agent SSH signing keys made in each scheduled session, public half in team/keys/, checked in CI. Proposal: (b), once each role runs in its own session (now the case for scheduled runs).
