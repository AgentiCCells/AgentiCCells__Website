# ACC-015 · The Agent: trailer is not being read by git
Owner: conductor@AgentiCCells.dinis · Status: Done (2026-11-15): build/check-commits.mjs runs in CI (dev@ 9b64de6)
Found by the reading (web-summit.sgit.ai/abp/dev-web-summit-dinis) and confirmed here on 2026-11-15: `git log --format='%(trailers:key=Agent)'` is empty for every commit so far, because `Agent:` sat in its own paragraph before the Co-Authored-By block, and git reads only the last paragraph as trailers.
Fix: from commit "Reading notes" onwards, `Agent:` goes in the same final block as the other trailers. Next: a check in CI that every non-merge commit on dev carries a readable `Agent:` trailer (a rule with no check is not enforced). Earlier commits are left as they are; history is not rewritten.
