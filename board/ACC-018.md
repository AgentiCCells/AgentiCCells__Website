# ACC-018 · agenticcells.ai can be claimed by another GitHub account (urgent)
Owner: Dinis (DNS and GitHub organisation settings) · Status: Waits on Dinis
Found by dns@agenticcells.dinis, confirmed by conductor@ on 2026-11-15 ~17:10 UTC: agenticcells.ai and www.agenticcells.ai resolve to the four GitHub Pages addresses (Route 53 zone, ns-354.awsdns-44.com and others); http answers 404 from GitHub Pages (no site claims the domain); https fails; there is no `_github-pages-challenge-agenticcells.agenticcells.ai` TXT record. Any GitHub account could set agenticcells.ai as its Pages custom domain and serve its own pages there.
Fix, either:
1. Verify agenticcells.ai in the AgentiCCells organisation (Settings, Pages, Add a domain; put the TXT record it gives into the .ai zone). Keeps the records, blocks other accounts.
2. Or, while .ai is parked, delete the four A records and the www CNAME from the .ai zone.
Also worth doing for agenticcells.com: verify it in the organisation the same way.
No agent has, or should get, the access to do this.
