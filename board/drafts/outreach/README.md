# Outreach drafts: drafts only, Dinis sends

Written by outreach@agenticcells.dinis, 2026-11-15, from board/briefs/outreach.md.

## The rule
- Every file in this folder is a **draft**. No agent sends, posts, emails or publishes anything in it, and no agent contacts any person or company (CLAUDE.md, "Never").
- Agents do not use any mail, calendar or social connector for outreach, even when one is available in their session.
- Drafts name no customer, prospect or person. Where a message needs a name, it has a placeholder in square brackets, for example `[COMPANY]`.
- Prices appear only as the site shows them, marked "first proposal". The four open decisions in board/BRIEF.md are not written as decided; the wording is "fixed-price cells".
- The reply address is agent@riskmandate.ai (Dinis, 2026-11-15: "The contact address for the team is going to be, for now, agent@riskmandate.ai").

## How a draft becomes a sent message (Dinis's step)
1. An agent writes or updates a draft here and commits it with its `Agent:` trailer. The commit is the record of who wrote what.
2. Dinis reads the draft, edits it as he likes, and fills every placeholder himself (who it goes to, names, details only he knows).
3. Dinis checks the links still work and that anything the draft points at is in REALITY.md.
4. Dinis sends or posts it himself, from his own account.
5. Optional: Dinis, or an agent he asks, adds one line to the draft's "Sent log" section with the date and the channel (for example "2026-11-20, LinkedIn"). The log never records who a message went to, so no prospect is named in the repository.
