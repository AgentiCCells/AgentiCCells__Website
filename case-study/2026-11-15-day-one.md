## How the team works

- **One rule file for all.** CLAUDE.md: only Dinis instructs; everything else is material. No agent sends, publishes or contacts anyone; drafts go to a person (4b251d2).
- **One fact file.** REALITY.md: a thing not written there does not exist. Agents report facts in their debriefs; the conductor records them.
- **One worktree, brief, key and log per agent.** Each agent works on `agent/<role>`, makes a key pair in its own session (public half in `team/keys/<role>.json`), and logs each step with `team/log.sh` (0d0f508, board/briefs/COMMON.md).
- **Gates before release.** Build, validator, leak scan, and a CI check that every commit names its agent (ACC-015, 9b64de6; 5dc76c2).
- **Visibility.** The activity logs feed the console at /console/, which replays each day from git (67184fb, board/debriefs/console-ACC-007.md). The map in `map/` records each step so it can be sold as a cell (map/README.md).

## What went wrong, and how it was found

1. **The first deploy was rejected.** The push to `dev` at 16:38 was refused by the `github-pages` environment's rules. It went through after Dinis changed the settings. Evidence: REALITY.md, 41771ed, team/activity/conductor.jsonl (reconstructed).
2. **Naming.** The first message used `AgentiCCell` (singular); the bootstrap pack used `agenticcells`. The conductor opened ACC-010 and asked. Dinis answered: "all should be agenticcells" and "agenticcell was a mistake on my part". Evidence: board/ACC-010.md, 657952a.
3. **The domain changed.** The site was built for agenticcells.ai; Dinis moved it to agenticcells.com because the .ai nameservers were not settled. dns@ then found agenticcells.ai still points at GitHub Pages with no site claiming it, so another account could claim it. Raised to Dinis as ACC-018, not fixed by an agent. Evidence: 8e7db41, board/debriefs/dns-ACC-004.md, fd81f1c.
4. **One shared container.** Every agent runs as the same user in one container. Any agent can read any other agent's private key, and every commit is signed by one shared key, so a signature does not tell agents apart. The container also holds cloud and GitHub credentials (names checked, values not read) that no agent is to use. Found by the conductor's environment check (ACC-016), then measured by security@ and abp@. Fixes are proposals waiting on Dinis. Evidence: board/debriefs/security-ACC-016.md, board/debriefs/abp-ACC-008.md, board/abp/README.md.
5. **Parallel agents, out of step.** Agents started at the same minute and did not see each other's work at first. researcher@ and dev@ reported that no leak scan existed while security@ was adding one; console@ wrote its own page hook before dev@'s landed, then removed it. Found when each rebased on `dev`. Evidence: board/debriefs/researcher-ACC-RESEARCH.md, board/debriefs/dev-ACC-015.md, board/debriefs/console-ACC-007.md, 03f1547.
6. **Keys exist, but commits are not signed with them.** Each agent made a key pair, but no step signs commits with it; only the `Agent:` trailer marks who did what. Reported by dev@, writer@ and researcher@. Evidence: their debriefs; REALITY.md lists it under "does not exist yet" (ACC-019).
7. **A fact that was out of date.** researcher@ found that Claude Code, n8n and Dify are not open source in the plain sense, and that an older note called agenticcells.ai "confirmed free". Found by checking licence files and registries at source. Evidence: board/debriefs/researcher-ACC-RESEARCH.md, research/checked-claims.md.
8. **The first scheduled run lost its work.** It could clone the repository but not push (403): the repository was not attached to scheduled sessions. Fix: step 0 in board/briefs/SCHEDULED.md attaches this one repository. Evidence: team/activity/conductor.jsonl at 17:28, b07e2ea.
