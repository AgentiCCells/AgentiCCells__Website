# The map: how this cell was set up, step by step

Dinis, 2026-11-15: "remember that we are still mapping on this, right? We basically, this is one of the things that we sell. So even what we're doing here, the visibility that we're selling here is actually what we actually are doing. So yeah, let's map the whole workflow. And even the creation of this website is something that we want to sell."

This folder maps our own setup as it happens, so the same steps can be sold as a cell. Every step names who did it, what it read, what it produced, and the evidence (commit, file or URL). Proposals are marked as proposals; reconstructed steps say so.

- `website-build.md`: building and releasing agenticcells.com, from an empty repository to a versioned live site.
- `team-setup.md`: starting a team of agents: roster, briefs, keys, policies, activity logs, the stop file.
- `website-cell.md`: the seven steps of the £500 website cell (first proposal, ACC-021), what exists and what does not.
- More maps as work arrives (customer-site pipeline, console).

Sources of truth the map points at, never restates: `board/`, `team/activity/*.jsonl`, `team/keys.json`, git history (`Agent:` trailers), `REALITY.md`.
